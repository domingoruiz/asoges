# Asoges

Sistema integral para la gestión de asociaciones

## Entorno de desarrollo
- Apple OS X 26.0 (Apple Silicon)
- Docker Compose [docker-lamp](https://github.com/domingoruiz/docker-lamp)
- PHP 8.4.8
- Mysql 8.0.42
- Laravel 12.19.3

## Comandos
Actualizar Composer 
- composer update

Crear módulo de nwidart/laravel-modules
- php artisan module:make

Ejecuta todas las migraciones y seeders
- php artisan migrate
- php artisan db:seed

Limpiar cache Laravel
- php artisan optimize:clear
